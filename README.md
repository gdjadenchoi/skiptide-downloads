# SKIPTIDE downloads

Public Android playtest downloads: **https://gdjadenchoi.github.io/skiptide-downloads/**

The page reads public GitHub Releases and selects the newest published release with an uploaded APK, including prereleases. Publish each new build as a release with an `.apk` attachment; the download button and update notes refresh when visitors open the page. No website edit is needed for each release.

If GitHub's API is unavailable or rate limited, the page keeps the verified v1.8 download and offers a link to the full release list. It does not install updates automatically.

GitHub Pages source: `codex/download-page`, repository root. Site changes pushed to this branch redeploy the page.
